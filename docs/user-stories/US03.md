# US03 – Leitura de código de barras

**Sprint 2** (17/11 – 30/11/2026) · **Estado:** 🟡 protótipo pronto (ecrã "Teste do leitor")

> Como funcionário, quero ler o código de barras com a câmara, para identificar o produto sem escrever.

## Acceptance Criteria
- [ ] **Autorização da câmara:** Dado a primeira utilização do leitor,
Quando o ecrã é aberto,
Então o Android pede autorização para usar a câmara; se for recusada, a aplicação explica como a ativar e oferece a pesquisa manual.
- [x] **Identificação automática:** Dado um produto registado,
Quando o funcionário aponta a câmara ao código de barras,
Então o produto é identificado automaticamente, sem internet, e o nome é mostrado no ecrã.
- [x] **Código inexistente:** Dado um código que não está registado,
Quando é lido,
Então a aplicação avisa que o código não existe.
- [ ] **Código danificado — escrever à mão:** Dado um código que a câmara não consegue ler,
Quando o funcionário escreve o código à mão,
Então o produto é identificado da mesma forma que pela câmara.
- [ ] **Código danificado — procurar pelo nome:** Dado um produto sem código legível,
Quando o funcionário procura pelo nome,
Então pode escolher o produto na lista de resultados.
- [x] **Sem leituras repetidas:** Dado um código acabado de ler,
Quando a câmara continua apontada ao mesmo produto,
Então o resultado não se repete até o funcionário pedir uma nova leitura.
- [x] **Privacidade:** Dado o uso da câmara,
Quando um código é lido,
Então nenhuma imagem é gravada ou enviada.

## Notes
- Tecnologia: **CameraX** (câmara) + **ML Kit Barcode Scanning** (reconhecimento, gratuito e offline). Formatos: EAN-13 (padrão), EAN-8, UPC-A/E, Code 128, Code 39, ITF, QR.
- Já feito no protótipo: leitura, aviso de código inexistente, bip, lanterna (extra, não exigida na proposta) e registo rápido de teste.
- A leitura só pode ser testada num **dispositivo real**; o emulador não tem câmara real.
- Pontos em aberto, a esclarecer com a cliente:
  - Quando o código não existe, a aplicação deve **oferecer o registo do produto** ali mesmo, ou só avisar?
  - Manter a lanterna? (Não custa nada, já está feita.)
