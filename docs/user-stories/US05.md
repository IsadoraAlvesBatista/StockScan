# US05 – Relatório de contagem

**Sprint 3** (01/12 – 15/12/2026) · **Estado:** ⏳ por fazer

> Como utilizador, quero gerar um relatório da contagem, para saber o estoque existente.

## Acceptance Criteria
- [ ] **Confirmação:** Dado uma contagem em curso com pelo menos um produto,
Quando o utilizador pede para gerar o relatório,
Então a aplicação pede confirmação, avisando que a contagem será reposta a zero.
- [ ] **Conteúdo do CSV:** Dado a confirmação,
Quando o relatório é gerado,
Então é criado um ficheiro CSV com uma linha por produto contado e as colunas: produto, código de barras, quantidade, data e hora e utilizador que fez a contagem.
- [ ] **Abre no Excel:** Dado o ficheiro CSV,
Quando é aberto no Excel (em português),
Então as colunas aparecem separadas e os acentos aparecem corretamente.
- [ ] **Guardar ou partilhar:** Dado um relatório gerado,
Quando o utilizador escolhe guardar ou partilhar,
Então pode guardar o ficheiro no tablet ou enviá-lo (por exemplo, por e-mail ou WhatsApp).
- [ ] **Histórico:** Dado relatórios já gerados,
Quando o utilizador abre a lista de relatórios,
Então vê todos os relatórios (data e hora, quem gerou, número de produtos) e pode voltar a partilhar qualquer um.
- [ ] **Novo ciclo:** Dado um relatório gerado com sucesso,
Quando o utilizador volta à contagem,
Então a contagem em curso está vazia.
- [ ] **Contagem vazia:** Dado que não há nenhum produto contado,
Quando o utilizador tenta gerar o relatório,
Então a aplicação avisa e não gera nenhum ficheiro.

- **NFR01:** funcionamento offline (a partilha usa as aplicações do tablet)
- **NFR02:** persistência local (novas tabelas de relatórios → migração da base de dados para a versão 2)

- **NFR05:** interface em português de Portugal

## Notes
- **Excel em português:** usar `;` como separador e gravar em UTF-8 com BOM. Com `,` e sem BOM, o Excel mete tudo numa coluna e estraga os acentos.
- O histórico guarda uma **cópia** do nome do produto e do utilizador no momento do relatório, para os relatórios antigos não mudarem se um produto for alterado ou um utilizador desativado.
- Nome do ficheiro proposto: `contagem_AAAA-MM-DD_HHmm.csv`.
- A geração do relatório e a reposição a zero são feitas na mesma transação: ou acontecem as duas, ou nenhuma (não se perde a contagem se algo falhar).
- Pontos em aberto, a esclarecer com a cliente:
  - Quem pode gerar o relatório: todos os utilizadores (como diz a proposta) ou só o Administrador?
  - Para onde é normalmente enviado o relatório (e-mail, WhatsApp, computador)?
