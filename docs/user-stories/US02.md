# US02 – Gestão de produtos

**Sprint 1** (02/11 – 16/11/2026) · **Estado:** ⏳ por fazer

> Como utilizador, quero consultar e registar produtos, para manter a lista do posto atualizada.

## Acceptance Criteria
- [ ] **Lista base:** Dado a lista de produtos enviada pela cliente (Excel ou CSV),
Quando a aplicação é instalada e aberta pela primeira vez,
Então todos os produtos da lista já estão disponíveis, sem nenhuma ação do utilizador.
- [ ] **Consultar:** Dado produtos registados,
Quando o utilizador abre o ecrã de produtos,
Então vê a lista ordenada por nome, com o nome e o código de barras de cada produto.
- [ ] **Pesquisar:** Dado o ecrã de produtos,
Quando o utilizador escreve parte do nome ou do código de barras,
Então a lista mostra só os produtos correspondentes (sem distinguir maiúsculas nem acentos no nome).
- [ ] **Registar:** Dado o ecrã de produtos,
Quando o utilizador insere um produto com nome e código de barras,
Então o produto fica guardado e aparece na lista; nome e código são obrigatórios.
- [ ] **Código único:** Dado um código de barras já registado,
Quando se tenta registar outro produto com o mesmo código,
Então é mostrado um erro (indicando o produto existente) e nada é guardado.
- [ ] **Persistência:** Dado produtos registados,
Quando a aplicação é fechada ou o tablet reiniciado,
Então os produtos continuam disponíveis.

## Notes
- **Decisão técnica proposta:** converter a lista da cliente para CSV e incluí-la na aplicação (`assets/produtos.csv`). A importação é feita automaticamente na primeira abertura. Ler Excel diretamente no tablet obrigaria a uma biblioteca pesada (Apache POI), desnecessária para uma lista fixa.
- O código de barras é guardado como texto (preserva zeros à esquerda). Os códigos do Excel devem vir como texto: se vierem como número, o Excel pode cortar zeros ou mostrar `7,89E+12`.
- Pontos em aberto, a esclarecer com a cliente:
  - Quem pode registar produtos: todos os utilizadores (como diz a proposta) ou só o Administrador?
  - É preciso **editar** ou **remover** produtos? (Não está na proposta.)
  - Se a lista base mudar no futuro, como é atualizada: nova versão da aplicação ou importação no tablet?
